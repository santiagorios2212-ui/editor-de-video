# Proyectos de Edición

Cada vez que edites un vídeo, la skill creará una carpeta dedicada para ese proyecto (ej: `proyectos/mi-primer-video/`).

Dentro de cada proyecto encontrarás:
- `PLAN.md`: Plan de edición detallado segundo a segundo (cortes, zooms, gráficos, subtítulos, audio).
- `ESTADO.md`: Registro de fases completadas y decisiones tomadas.
- `trabajo/`: Archivos intermedios y transcripciones con marcas de tiempo.
- `entrega/`: Kit por capas listo para importar en CapCut u otro software de edición, más el archivo `revision.mp4`.
