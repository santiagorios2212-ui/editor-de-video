# Branding del Creador

Coloca aquí los activos de identidad visual de tu canal o marca:

- `logo.png`: Logotipo o isotipo en formato PNG transparente.
- `fuentes/`: Tipografías personalizadas (`.otf` o `.ttf`) para titulares y subtítulos.
- `luts/`: Archivos `.cube` para la gradación de color (LUTs).

Cuando ejecutes la skill por primera vez, el asistente te ayudará a configurar la paleta de colores y tipografías en tu `perfil-creador.md`.
