# Vídeos de Referencia

Añade aquí vídeos de otros creadores o canales que te gusten para analizar su edición y extraer su lógica:

1. Crea una carpeta con el nombre de la referencia (ej: `referencias/canal_ejemplo/`).
2. Coloca el vídeo dentro.
3. Pídele al editor: *"analiza la edición de este vídeo"*.
4. Se generará un análisis de ritmo, planos, subtítulos, efectos y motion graphics sin copiar contenido literal.
