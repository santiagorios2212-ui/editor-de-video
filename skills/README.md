# Catálogo de Skills

Este directorio contiene las skills especializadas que potencian y asisten a `editor-video`:

| Grupo | Skills | Origen |
|---|---|---|
| **Skill Principal** | `editor-video`, `planificador-video`, `nutrir-editor` | Editor de vídeo con criterio propio y planificación por capas |
| **Remotion oficial** | `remotion-*` (12 skills) | github.com/remotion-dev/skills |
| **Motion graphics HyperFrames** | `motion-graphics` + `hyperframes-*`, `media-use` | github.com/heygen-com/hyperframes |
| **Fundamentos de motion design** | `animation-principles`, `motion-art-direction`, `shot-composition`, `color-motion`, `logo-animation`, `motion-background`, `beat-sync-editing`, `after-effects`, `remotion-video` | github.com/iart-ai/motion-design-skills |
| **Remotion motion graphics** | `remotion-motion-graphics` | github.com/haidrrrry/claude-remotion-skill |
| **Corte** | `cut-video` | github.com/louisedesadeleer/cut-video |
| **Edición complementaria** | `video-use` | github.com/browser-use/video-use |

### Privacidad y Funcionamiento Local
- **Telemetría desactivada:** Toda telemetría externa ha sido desactivada por defecto. El sistema opera 100% en local.
- **Sin necesidad de APIs externas:** La skill principal utiliza Whisper y FFmpeg de forma local. No requiere ninguna clave de API ni conexión a internet para editar y generar los kits de montaje.
