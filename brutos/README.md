# Vídeos Brutos (Grabaciones Originales)

Deposita aquí los vídeos originales sin editar (`.mp4`, `.mov`, `.mkv`, etc.).

### Regla fundamental
* Los archivos brutos **nunca se modifican ni se sobrescriben**. La skill los lee de forma segura para cortar, transcribir y estructurar las tomas en la carpeta `proyectos/`.
