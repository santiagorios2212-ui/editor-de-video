# Recursos y Efectos de Sonido

En esta carpeta se almacenan los recursos auxiliares de edición:

- `sfx/`: Pack de 19 efectos de sonido sintetizados y libres de derechos listos para usar (`whoosh`, `impacto`, `pop`, `ding`, `riser`, `clic`, etc.). Puedes añadir tus propios efectos de sonido `.wav`.
- `musica/`: Pistas de audio y música de fondo con licencia.
- `broll/`: Clips de apoyo, recursos visuales o imágenes complementarias.
